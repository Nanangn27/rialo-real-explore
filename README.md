# Rialo Explorer

Build Phase 1 of a browser-based 3D location exploration game called Rialo Explorer.



Use the Rialo logo image that I uploaded as the official brand logo. Do not redesign or replace it.



Vision



Create a real-world exploration experience where players explore the real map of Central Java using their real location. The player is represented by a lightweight 3D explorer character.



Phase 1 Main Features



1. Landing Screen



Create a premium exploration game landing page.



Include:



- Uploaded Rialo logo

- Title: Rialo Explorer

- Subtitle: Explore The Real World

- Main button: Start Exploring



Style:



- Bright daytime atmosphere

- Futuristic but clean

- Professional Web3 game feeling

- Smooth animations



2. Wallet Connection



Add:



- Connect Wallet button

- Wallet connected status

- Short wallet address display



Do not require transactions yet.



3. Real World Map



Create a real interactive map.



Requirements:



- Initial location: Central Java, Indonesia

- Real roads and locations

- Zoom and pan support

- Mobile friendly

- Show player's real GPS location

- Use browser geolocation permission

- Display a player marker



The map should feel like a real exploration game, not a simple map app.



4. 3D Explorer Character



Add a lightweight 3D player character.



Requirements:



- Explorer style character

- Visible on top of the map

- Represents the player's GPS position

- Idle animation

- Walking animation when movement is detected (if possible)

- Optimized for mobile browsers



5. Game Interface HUD



Add a clean game HUD:



Display:



- Rialo logo

- Explorer Level: 1

- XP: 0

- Current location

- Inventory button

- Profile button

- Discovery button (placeholder)



6. Daytime Environment



The visual atmosphere should be:



- Bright daylight

- Clear sky feeling

- Natural exploration mood

- Modern futuristic Rialo style



Do not create a dark night theme for this phase.



7. Future Ready Structure



Prepare the code structure for future features:



- 3D discoveries

- Relics

- Mystery boxes

- Portals

- NPC characters

- Quests

- Inventory system

- XP progression

- Achievements

- Rialo blockchain integration

- Multiplayer events



Do not build these systems yet.



Technical Requirements



- React + TypeScript

- Clean modular components

- Lightweight Three.js / React Three Fiber implementation

- Real map integration

- Real GPS support

- Responsive on Android, iPhone, tablet, and desktop

- Must build successfully

- Must be deployable to Vercel



Priority:



1. Stable real map

2. GPS player location

3. 3D explorer character

4. Rialo branding

5. Smooth mobile experience



Create a polished foundation for future phases of Rialo Explorer.
